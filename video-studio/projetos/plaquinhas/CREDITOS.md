# Créditos dos recursos

- Modelos de animação: [HyperFrames](https://github.com/heygen-com/hyperframes) (HeyGen), Apache 2.0.
- Efeitos sonoros (`assets/sfx/`): Pixabay, via HyperFrames; licença Pixabay (uso comercial sem atribuição).
- Emojis animados (`assets/lottie/`): Noto Animated Emoji (Google), CC BY 4.0.
- Fundo: Jitsi Meet virtual background, Apache 2.0.
- GSAP 3.14.2 e lottie-web 5.12.2 (npm).

`assets/base.mp4` e `assets/voz.wav` não estão no git (gerados por `render.py` a partir do vídeo bruto).
